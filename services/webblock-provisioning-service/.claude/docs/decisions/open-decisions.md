# Open decisions

Unresolved decisions and contract gaps for the Provisioning service. An entry here blocks only the feature that depends
on it; independent work continues. Nothing in this file is an agreed contract. Resolved items move to a numbered
decision record in this directory.

Status values: **open** (no decision), **draft** (Provisioning has a working assumption recorded in a decision record,
awaiting review), **blocked-external** (needs another service's owner).
